# pullquote

A line from the post, set large between paragraphs.

**Use when** the author asks to emphasise a line, or one sentence carries the post. Suggest it in chat; add it only on a yes.

**Inputs (text):** the quote, exactly as it appears in the author's text. An optional last line starting with `--` is the attribution.

```text
::: pullquote
A draft is just a post you haven't shared yet.
:::
```

Only the author's own words. Never write a new line for a pull quote, and never quote someone else without the author saying so.
