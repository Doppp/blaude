# projects

Things the author made: a name (linked) and a one-line description.

```json
{ "type": "projects", "id": "projects", "title": "Projects", "items": [
  { "name": "Blaude", "url": "https://github.com/Doppp/blaude", "description": "Blogging with Claude." }
] }
```

- `id` is required and unique. Items keep the order given.
- Items: `name` (required), `url` (optional), `description` (optional, one line).
